## Step 4: G1 训练

**前置**：Step 2 + Step 3 都完成。

### 4.1 确认 Hallo3 预训练权重就绪

```bash
cat /scratch/li_qiany_neu/pretrained_models/hallo3/latest
ls /scratch/li_qiany_neu/pretrained_models/hallo3/1/mp_rank_00_model_states.pt
```

### 4.2 创建训练配置

```bash
cat > ~/hallo3/configs/sft_g1_train.yaml << 'EOF'
args:
  checkpoint_activations: True
  model_parallel_size: 1
  experiment_name: train-g1-omnilingual-adapter
  mode: finetune

  load: /scratch/li_qiany_neu/pretrained_models/hallo3

  no_load_rng: True
  train_iters: 7000
  eval_iters: 1
  eval_interval: 99999
  eval_batch_size: 1
  save: /scratch/li_qiany_neu/train_output_g1
  save_interval: 1000
  overwrite: True
  log_interval: 1
  train_data: [
    "../data/talkvid_train_2700_omnilingual.json",
  ]
  valid_data: [
    "../data/talkvid_train_2700_omnilingual.json",
  ]
  split: 1,0,0
  num_workers: 2
  force_train: True
  only_log_video_latents: True

data:
  target: data_video.Stage2_SFTDataset
  params:
    video_size: [ 480, 720 ]
    fps: 8
    max_num_frames: 49
    skip_frms_num: 3.

deepspeed:
  train_micro_batch_size_per_gpu: 1
  gradient_accumulation_steps: 1
  steps_per_print: 10
  gradient_clipping: 0.1
  zero_optimization:
    stage: 2
    cpu_offload: false
    contiguous_gradients: false
    overlap_comm: true
    reduce_scatter: true
    reduce_bucket_size: 1000000000
    allgather_bucket_size: 1000000000
    load_from_fp32_weights: false
  zero_allow_untested_optimizer: true
  bf16:
      enabled: True
  fp16:
      enabled: False
  loss_scale: 0
  loss_scale_window: 400
  hysteresis: 2
  min_loss_scale: 1

  optimizer:
    type: AdamW
    params:
      lr: 1e-5
      betas: [ 0.9, 0.95 ]
      eps: 1e-8
      weight_decay: 1e-4
  activation_checkpointing:
    partition_activations: false
    cpu_checkpointing: true
    contiguous_memory_optimization: true
    profile: false
  wall_clock_breakdown: false
EOF
```

### 4.3 启动训练（2 GPU, rtx-devel 2h 或 rtx-batch 24h）

```bash
# 申请节点（rtx-batch 更适合长训练）
srun --partition=rtx-devel --nodes=1 --gpus=2 --cpus-per-task=16 --mem=256G --time=02:00:00 --account=p2026_0014_neu --pty bash

# 环境初始化
module load cuda/13.1.1
export LD_LIBRARY_PATH=$CONDA_PREFIX/lib:$LD_LIBRARY_PATH
conda activate hallo3
cd ~/hallo3/hallo3

# 训练
PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True \
torchrun --standalone --nproc_per_node=2 \
    train_video.py \
    --base ../configs/cogvideox_5b_i2v_s2.yaml ../configs/sft_g1_train.yaml \
    --seed 42 2>&1 | tee /scratch/li_qiany_neu/hallo3_logs/train_g1_$(date +%m-%d-%H-%M).log
```

**预期 checkpoint 加载 log**：
```
Missing keys: ['audio_proj.adapter.weight', 'audio_proj.adapter.bias']
```
这是正常的（adapter 随机初始化）。不应出现 `Skipped shape-mismatched keys`。

**如果 rtx-devel 2h 超时**：训练会自动从最新 checkpoint 续训，重新申请节点跑同一命令。

**预估**：7000 步 × ~9s/iter ÷ 2 GPU ≈ ~9 小时，rtx-devel 需要 ~5 次续训。

## Step 5: G1 推理 + SyncNet 打分

**前置**：Step 4 完成至少一个 checkpoint。

### 5.1 创建推理 overlay yaml

```bash
# 用最新（或最佳）checkpoint
CKPT_DIR=$(ls -dt /scratch/li_qiany_neu/train_output_g1/train-g1-*/ | head -1)
echo "Using checkpoint: $CKPT_DIR"

cat > /tmp/infer_g1.yaml << EOF
args:
  load: $CKPT_DIR
EOF
```

### 5.2 val5 快速推理

```bash
cd ~/hallo3/hallo3

TORCH_FORCE_NO_WEIGHTS_ONLY_LOAD=1 PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True \
WORLD_SIZE=1 RANK=0 LOCAL_RANK=0 LOCAL_WORLD_SIZE=1 \
python sample_video.py \
    --base ../configs/cogvideox_5b_i2v_s2.yaml ../configs/inference.yaml /tmp/infer_g1.yaml \
    --seed 42 \
    --wav2vec_model_path /scratch/li_qiany_neu/pretrained_models/omnilingual-w2v2-300m \
    --input-file ../my_inference/input_val5.txt \
    --output-dir /scratch/li_qiany_neu/infer_out/g1_val5
```

> 不传 `--vae_checkpoint`（走 wav2vec 分支，不走 LTX-2 VAE）。

### 5.3 SyncNet 打分

```bash
conda activate syncnet
cd ~/syncnet_python
OUT=/scratch/li_qiany_neu/syncnet_out

for dir in /scratch/li_qiany_neu/infer_out/g1_val5/000000-*-seed_42; do
  stem=$(basename "$dir" | sed 's/^000000-//; s/-seed_42$//')
  vid="$dir/000000_with_audio.mp4"
  [ -f "$vid" ] || continue
  echo "=== g1_$stem"
  python run_pipeline.py --videofile "$vid" --reference "g1_$stem" --data_dir "$OUT" </dev/null
  python run_syncnet.py  --videofile "$vid" --reference "g1_$stem" --data_dir "$OUT" </dev/null
done 2>&1 | tee $OUT/g1_val5.log | grep -E "^===|AV offset|Min dist|Confidence|Error"
```

### 5.4 汇总结果

```bash
grep "Confidence:" $OUT/g1_val5.log | awk '{print $NF}' | awk '{s+=$1; n++} END {printf "G1 val5 Confidence avg: %.3f (n=%d)\n", s/n, n}'
grep "Min dist:" $OUT/g1_val5.log | awk '{print $NF}' | awk '{s+=$1; n++} END {printf "G1 val5 Min dist avg:   %.3f (n=%d)\n", s/n, n}'
grep "AV offset:" $OUT/g1_val5.log | awk '{print $NF}' | awk '{s+=$1; n++} END {printf "G1 val5 AV offset avg:  %.2f (n=%d)\n", s/n, n}'
```

**成功标准**：

| 层级 | 标准 |
|------|------|
| 最低 | conf > 1（超过 G4 的 1.04） |
| 及格 | conf > 3 |
| 良好 | conf > 5 |
| 优秀 | conf ≈ 6.33（B1 水平） |
