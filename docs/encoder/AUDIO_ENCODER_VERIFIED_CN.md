## 二、AudioProjModel 结构图

```
┌─────────────────────────────────────────────────────────────────────────┐
│                                                                         │
│                     AudioProjModel 结构                                 │
│          将 audio embedding 投影到 Transformer 隐空间                    │
│                                                                         │
│    输入: (B, 49, 5, 1, 128)                                             │
│           │  │  │  │   └── channels (8ch × 16mel = 128)                 │
│           │  │  │  └────── blocks (VAE=1, Wav2Vec=12)                   │
│           │  │  └───────── window (±2帧 = 5)                            │
│           │  └──────────── frames (49 视频帧)                            │
│           └─────────────── batch                                        │
│                                                                         │
│    ┌───────────────────────────────────────────────────┐                │
│    │  Step 1: Flatten                                  │                │
│    │                                                   │                │
│    │  rearrange "bz f w b c → (bz×f) w b c"           │                │
│    │  → (B×49, 5, 1, 128)                              │                │
│    │                                                   │                │
│    │  view → (B×49, 640)      ← 5 × 1 × 128 = 640    │                │
│    └───────────────────┬───────────────────────────────┘                │
│                        │                                                │
│    ┌───────────────────▼───────────────────────────────┐                │
│    │  Step 2: MLP Projection                           │                │
│    │                                                   │                │
│    │  proj1: Linear(640 → 512) + ReLU                  │                │
│    │  proj2: Linear(512 → 512) + ReLU                  │                │
│    │  proj3: Linear(512 → 24576) + reshape             │                │
│    │         24576 = 32 tokens × 768 dim               │                │
│    │  → (B×49, 32, 768)                                │                │
│    └───────────────────┬───────────────────────────────┘                │
│                        │                                                │
│    ┌───────────────────▼───────────────────────────────┐                │
│    │  Step 3: Temporal Compression                     │                │
│    │                                                   │                │
│    │  rearrange → (B, 49, 24576)                       │                │
│    │                                                   │                │
│    │  Conv1d(k=2, s=2) 第1次: 49帧 → 25帧              │                │
│    │  (奇数帧: 保留首帧, 其余conv)                       │                │
│    │                                                   │                │
│    │  Conv1d(k=2, s=2) 第2次: 25帧 → 13帧              │                │
│    │  (奇数帧: 保留首帧, 其余conv)                       │                │
│    │                                                   │                │
│    │  49 → 25 → 13  与视频 latent 时间维度对齐!          │                │
│    └───────────────────┬───────────────────────────────┘                │
│                        │                                                │
│    ┌───────────────────▼───────────────────────────────┐                │
│    │  Step 4: Output                                   │                │
│    │                                                   │                │
│    │  rearrange "b f (m c) → b f m c" m=32             │                │
│    │  LayerNorm(768)                                   │                │
│    │  → (B, 13, 32, 768)                               │                │
│    │     │   │   │    └── hidden dim (= Transformer)    │                │
│    │     │   │   └─────── 32 context tokens / 帧        │                │
│    │     │   └─────────── 13 时间帧 (= 视频 latent)     │                │
│    │     └─────────────── batch                         │                │
│    └───────────────────────────────────────────────────┘                │
│                                                                         │
│    → 送入 Transformer 各层做 cross-attention                             │
│      视频 latent query 这 32 个 audio token                             │
│      学会 "这一帧该张什么嘴型"                                           │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

## 四、维度对齐速查

| 阶段 | 实测 shape | 说明 |
|------|-----------|------|
| audio_emb .pt 文件 | `(254, 128)` | 10秒×25fps, 8ch×16mel |
| 窗口采样后 | `(49, 5, 128)` | 49帧, ±2窗口 |
| unsqueeze blocks | `(49, 5, 1, 128)` | 补 blocks=1 |
| batch collate | `(1, 49, 5, 1, 128)` | B=1 |
| AudioProjModel 输出 | `(1, 13, 32, 768)` | 时间压缩到13帧 |
| 视频 raw | `(1, 49, 3, 480, 720)` | 49帧 RGB |
| 视频 VAE latent | `(1, 13, 16, 60, 90)` | 时间÷4, 空间÷8 |
| **音频 13帧 = 视频 13帧** | **对齐** | cross-attention 逐帧配对 |
